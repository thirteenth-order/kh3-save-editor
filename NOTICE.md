# Notices and attribution

This is the full version of the short notice in the interface and the README.
It exists so that nobody has to guess what this program contains, and so that a
rights holder who lands here can see the answer without reading the source.

`kh3save` is an unofficial, fan-made, offline tool for editing save files that
are already on the machine it runs on. It is not a game, it does not contain a
game, and it does not distribute any part of one.

## 1. No game assets are included

**No artwork, image, texture, model, animation, audio, music, video, font or
dialogue from KINGDOM HEARTS, or from any other Square Enix or Disney
property, is bundled with this program, distributed with it, or displayed by
it.** Not in the binary, not in the repository, not in the container images,
not in the release archives.

That is a design rule, not an accident, and the repository is arranged to keep
it true:

- Every mark, sigil and ornament in the interface is original geometry, with
  exactly three exceptions: the platform marks in section 3. The rose window
  and its bezel are generated by `tools/gen_emblem.py`, which carries the
  construction; the interface icons are drawn by hand in
  `internal/gui/assets/index.html`. CI fails if the generated artwork drifts
  from its generator.
- The screenshots and terminal recordings in `media/` are generated by
  `tools/demo/shoot.sh` and `tools/demo/record.sh` from a synthetic save this
  project builds itself. They show this program's own interface and nothing
  else.

## 2. About the names the program shows

The program displays short names for items, abilities, keyblades, worlds,
locations and playable characters: "Potion", "Kingdom Key", "Olympus".

These are labels for numbers stored in the user's own save file. A save records
that accessory slot 0 holds id 1; without a name, an editor can only offer the
reader the number, and the reader has no way to tell a keyblade from a snack.
The names are used descriptively, to identify which value is which, and for no
other purpose.

They are generated at build time by `tools/gen_tables.py` from the public enum
lists in [Xeeynamo/KingdomSaveEditor][upstream], which is GPL-3.0, and they are
facts about a file format rather than creative content. **No dialogue, script,
story text, lyrics, or other creative writing from the game is included.**

[upstream]: https://github.com/Xeeynamo/KingdomSaveEditor

## 6. What it does with a save

It reads and writes files that are already on the machine it runs on, and it
does nothing else with them. It has no network client. The interface listens on
`127.0.0.1` only and is reachable solely by a token minted for that run. Nothing
is uploaded, transmitted, collected, or phoned home, and no telemetry of any
kind exists in this program.

Every write is preceded by a timestamped backup, and the result is re-read and
re-validated before it is committed to disk.

## 7. Format documentation

The save format was reverse engineered for interoperability, from files the
authors owned, without decompiling or modifying the game. What is documented in
this repository is a description of a file layout: offsets, sizes and integrity
fields. No game code is included, disassembled or distributed.
